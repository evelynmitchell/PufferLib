**File**: `pyproject.toml:236-240`

#### 2. Configured Coverage Settings

Added `[tool.coverage.run]`, `[tool.coverage.report]`, and `[tool.coverage.html]` sections:

**Coverage Scope** (`pyproject.toml:258-268`):
- Source: `pufferlib` package
- Omitted from coverage:
  - `*/tests/*` - Test files themselves
  - `*/test_*.py` - Test modules
  - `*/ocean/*` - C extension environments (50 games)
  - `*/extensions/*` - C/CUDA extensions
  - `setup.py` - Build script

**Rationale**: Python coverage tools cannot measure C/C++/CUDA code. Ocean environments and extensions are written in C for performance (3.7M+ steps/second).

**Report Configuration** (`pyproject.toml:270-282`):
- Precision: 2 decimal places
- Show missing lines
- Branch coverage enabled
- Exclude standard patterns (pragma, __repr__, TYPE_CHECKING, etc.)

**Output Formats**:
- Terminal: Line-by-line missing coverage
- HTML: Interactive browsable report (htmlcov/)
- XML: Machine-readable format

#### 3. Configured Pytest

Added `[tool.pytest.ini_options]` section (`pyproject.toml:287-305`):

**Test Discovery**:
- Test paths: `tests/`
- File pattern: `test_*.py`
- Function pattern: `test_*`

**Default Arguments**:
- `-v` - Verbose output
- `--strict-markers` - Fail on unregistered markers
- `--cov=pufferlib` - Measure coverage
- `--cov-report=term-missing` - Show missing lines in terminal
- `--cov-report=html` - Generate HTML report
- `--cov-report=xml` - Generate XML report

**Test Markers**:
- `slow` - Long-running tests (can skip with `-m "not slow"`)
- `cuda` - Tests requiring CUDA
- `optional` - Tests for optional dependencies
